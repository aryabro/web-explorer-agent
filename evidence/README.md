# Evidence

`fixture/` is reproducible local integration evidence generated by
`scripts/generate_fixture_artifacts.py`. It drives the real Night Window browser
surface, but its discovery runs use
`fixture-model-not-submission-evidence`. They prove the compiler, deterministic
replay, locator agreement, tenant overlays, business-outcome, recovery, failure
screenshot, mutating flow, and session-storage oracle paths. They **do not**
satisfy the assignment's genuine LLM discovery requirement.

`discovery-20260914T225626Z-673c5e/` is the successful genuine
Gemini-driven run. It completed the live UI goal in eight model decisions and
compiled `capabilities/member.read_savings_balance.json`.

The retained top-level `replay-*` directories were produced against that compiled
artifact with `llm_calls: 0`:

- older CLI runs: success, `MEMBER_NOT_FOUND`, recovered interstitial, session expiry
- `replay-locator-votes/` — agreement telemetry (semantic+structural+geometry)
- `replay-northbay/` — same capability on `/tenant-b/` via `tenants/northbay.yaml`
- `replay-northbay-drift/` — unpatched tenant-b run; semantic lost, checkpoint failed
- `replay-draft-denied/` — unattended replay rejected while status is `draft`

`catalog.json` is the `list` / `tools` dump of the local capability catalog.

Regenerate the parity evidence (does not overwrite the genuine capability):

```bash
python -m target.server
python scripts/generate_parity_evidence.py
```

A new genuine discovery can be produced with:

```bash
pigeonhole discover --job jobs/read_savings.yaml --input member_id=12345 --headed
pigeonhole approve --capability capabilities/member.read_savings_balance.json --by reviewer
```

That run requires `CUA_LLM_API_KEY` and writes its actual model name into
`manifest.json`.

Persisted files are redacted. Runtime results returned to the local caller can
contain declared outputs; committed JSON/JSONL and screenshots must not.
